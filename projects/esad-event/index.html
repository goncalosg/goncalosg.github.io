ESAD.CR Event

Project Type Mobile App Design
My contribution Wireframing | Interface Design
Tools Figma
Project Team Gonçalo Gomes | Guilherme Nelas
Year 2023

The Events App was developed at the School of Arts and Design in Caldas da Rainha (ESAD.CR) as part of the Fundamentals of Interaction class in the Multimedia Design program. The goal of this academic project was to create a mobile application that streamlines the organisation and participation in school events, enabling students and teachers to explore, create, and manage events with ease.

Approach

Simplifying Event Organization
Through Mobile Design

The ESAD.CR Events App was developed using a user-centered approach to improve how students and teachers explore, create, and manage school events. User flows and core features were defined early to ensure clarity and efficiency. Wireframes structured navigation and key interactions, followed by the creation of a consistent visual system adapted for mobile. Through iterative refinement, the project evolved into a clear and accessible event management experience tailored to the academic community.
